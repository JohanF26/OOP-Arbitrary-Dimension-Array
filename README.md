Multi-Dimensional Array Implementation with Iterators

- Developed a C++ template class for multi-dimensional arrays, supporting variable dimensions with compile-time safety checks.
- Implemented custom iterators to traverse arrays in both first and last dimension major orders, ensuring efficient element access and manipulation.
- Integrated robust error handling mechanisms with custom exceptions for out-of-range index access.
- Utilized C++ template metaprogramming techniques to handle dynamic array creation, copy constructors, assignment operators, and range-checked indexing.
- Emphasized maintainability and extendibility through clear iterator interface design and adherence to C++ best practices.
